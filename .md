# Layer Width Formula — SmallMLP

## Context

Adaptive MLP for small classification datasets ($n < 500$). Width is computed from dataset parameters $(n, d, K)$, eliminating architecture search.

## Formula

**First layer:**

$$
w_1 = \max\left(2K, \; \min\left(\left\lfloor \alpha \cdot \sqrt{n \cdot K \cdot \sqrt{d}} \right\rfloor, \; 4n\right)\right)
$$

**Subsequent layers** ($l = 2, 3, \ldots, L$):

$$
w_l = \max\left(K, \; \left\lfloor w_1 \cdot \beta^{\,l-1} \right\rfloor\right)
$$

**Where:**

| Symbol     | Meaning          | Current value |
| ---------- | ---------------- | ------------- |
| $n$      | training samples | —            |
| $d$      | features         | —            |
| $K$      | classes          | —            |
| $\alpha$ | global scale     | $4.0$       |
| $\beta$  | depth decay      | $0.7$       |
| $L$      | number of layers | $2$         |

## Term-by-term motivation

**$\sqrt{n \cdot K \cdot \sqrt{d}}$** — composite complexity scale:

- $n^{1/2}$ — sublinear growth with data
- $K^{1/2}$ — sublinear growth with class count
- $d^{1/4}$ — very weak growth with feature count

**Lower bounds:**

- $w_1 \geq 2K$ — at least 2 units per class in the first layer
- $w_l \geq K$ for $l > 1$ — at least 1 unit per class in later layers

**Upper bound:**

- $w_1 \leq 4n$ — prevents width exceeding dataset size

**Decay:**

- $w_l \propto \beta^{\,l-1}$ — later layers narrower than earlier ones

## Empirical observations

On 18 small classification datasets (binary + multiclass, $n < 500$):

- $\alpha \in [1, 8]$ → mean accuracy $0.809$–$0.814$ (differences within noise)
- $\beta \in \{0.5, 0.7, 1.0\}$ → no significant difference
- The formula matches fixed width $\min(2n, 128)$ within noise, but does not consistently beat it
- On hard multiclass ($K > 5$), higher $\alpha$ helps slightly

## Questions for improvement

1. **Functional form.** Is $\sqrt{n \cdot K \cdot \sqrt{d}}$ theoretically justified, or is there a more principled scaling from statistical learning theory (VC dimension, Rademacher complexity, generalization bounds)?
2. **Lower bounds.** Is $2K$ / $K$ reasonable, or should they depend on $n$ or $d$?
3. **Upper bound.** Is $4n$ too weak? For $n = 500$, this allows $2000$ units. Would a cap tied to $n/K$ (samples per class) or a capacity measure be more principled?
4. **Decay.** Is exponential decay $\beta^{\,l-1}$ correct, or should width decay follow a different law (e.g., $1/l$, or depend on $d$)?
5. **Generalization bound.** Can a data-dependent generalization bound justify a specific width scaling?
6. **Literature.** Are there known width-scaling formulas for small-data classification? I've looked at VC dimension ($O(W \log W)$), linear regression ($d$ parameters), and recent scaling laws (Kaplan 2020, Hoffmann 2022 — but these are for LLMs, not small data). Nothing specific to $n < 500$ classification.

## What I'm not claiming

- The formula is not theoretically grounded — it is empirical.
- It matches, but does not consistently beat, a fixed-width baseline.
- Goal of this discussion: understand whether it can be made principled, or whether to abandon it for a simpler baseline.
